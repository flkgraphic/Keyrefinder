# Content-Architektur & Topic Cluster Modell

## Grundprinzip
Eine Seite = eine Suchabsicht = ein Keyword-Cluster.
Niemals mehrere verschiedene Suchabsichten auf einer Seite mischen.
Jede Cluster Page rankt auf eigene Keywords und verlinkt zurück zur Pillar Page.

---

## Seitenarchitektur — Übersicht

```
Homepage /de/                          ← Pillar Page
│
├── /de/wie-es-funktioniert/           ← Cluster: Ablauf & Vertrauen
├── /de/materialien/                   ← Cluster: Produkt & Qualität
├── /de/schluessel-gefunden/           ← Cluster: Finder-Perspektive ★ stärkstes Keyword
├── /de/schluessel-verloren/           ← Cluster: Besitzer-Perspektive
├── /de/datenschutz-anonym/            ← Cluster: Vertrauen & Sicherheit
├── /de/faq/                           ← FAQ (Rich Snippets)
├── /de/ueber-uns/                     ← Brand & Vertrauen
└── /de/kontakt/                       ← Conversion
```

Alle Cluster Pages existieren in allen 4 Sprachen mit übersetzten URL-Slugs.

## Pillar Page — Homepage `/de/`

**Suchabsicht:** Wer ist keyrefinder.ch, was bietet der Service?
**Primärkeyword:** `Schlüsselfinder Schweiz`
**Sekundärkeywords:** `Schlüssel verloren Schweiz`, `Schlüssel zurückgeben anonym`

**Inhalt:**
- Was ist keyrefinder.ch — klare, präzise Erklärung in 2–3 Sätzen ganz oben
- Wie funktioniert es — Kurzversion (3 Schritte), Verlinkung auf `/de/wie-es-funktioniert/`
- Warum keyrefinder — USPs (anonym, sicher, schweizweit)
- Vertrauen — Referenzen, Logos bekannter Kunden
- CTA — klarer Aufruf zur Aktion

**Interne Links von hier zu:**
Alle Cluster Pages sind von der Homepage aus verlinkbar (Navigation oder im Text).

## Interne Verlinkungsregeln

- Jede Cluster Page verlinkt zurück zur Homepage
- Cluster Pages verlinken untereinander wo thematisch sinnvoll
- Homepage verlinkt zu allen Cluster Pages (Navigation oder Body-Text)
- Anchor Text immer beschreibend: nicht "hier klicken" sondern "wie keyrefinder funktioniert"
- Keine Orphan Pages — jede neue Seite sofort in Navigation oder bestehendem Text verlinken
- Neue Cluster Pages immer in `sitemap.xml` + `llms.txt` eintragen

---

## Content-Qualitätsregeln

- Mindestlänge pro Cluster Page: 400 Wörter
- Primärkeyword in H1, in den ersten 100 Wörtern, und 2–3x im Text
- Keyword natürlich einbauen — nie mehr als einmal pro Absatz
- Jede Seite endet mit einem klaren CTA (z.B. "Jetzt Schlüssel registrieren" oder Link zur Offerte)
- Kein Content Copy-Paste zwischen Sprachversionen — echte Übersetzungen, keine Duplikate
